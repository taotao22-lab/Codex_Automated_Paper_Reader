## Code Agent

### 1. LoopVSR: A Loop Engineering Framework for Automated Repair of Visual Speech Recognition Inference Pipelines

- 问题背景：VSR 推理链路包含视频解码、嘴部区域提取、预处理、模型调用和解码。传统自动修复常依赖单元测试或静态规则，但这类多阶段 AI 推理管线的问题会互相遮蔽：上游加载失败时，下游张量分布、识别错误和 CER 根本暴露不出来。
- 核心方法：LoopVSR 把代码 agent 放进一个受限可编辑 workspace，外部 controller 保留评测权威。agent 每轮只提出一个主要故障假设和最小补丁；controller 审计补丁、运行真实 VSR 推理、返回失败样本数、异常、张量统计、代表性高错样本和 CER，然后按“失败数优先、CER 次之”的规则接受或回滚。直观地说，它把“跑测试”升级成“跑真实任务闭环”，让每次执行恢复都产生下一轮诊断证据。
- 创新点：论文明确提出 Loop Engineering：工程师不只是写 prompt，而是定义目标、工具、边界、评测、状态、停止条件和回滚策略。对 Code Agent 训练很有价值，因为它把补丁质量绑定到外部不可篡改的任务指标，而不是 agent 自评或文本相似度。
- 实验与 benchmark：在 CMLR video-only VSR 系统上构造 13 个确定性候选故障，最终主实验覆盖 11 个会造成 CER 退化的故障；Repair-dev 为 20 个训练集视频，Hidden200 为 200 个验证视频。LoopVSR 修复 11/11 个主故障，平均恢复 100%；Static guard 只修复 2/11，平均恢复 18.13%。它还在三个级联故障任务中用 7 个接受迭代完成修复，并在 Hidden200 上验证泛化。
- 可迁移价值：非常适合作为 Code Agent post-training 环境模板：受限编辑区、不可变 evaluator、运行时 telemetry、回滚、隐藏集验证都可以直接迁移到 SWE-bench 类任务或 ML pipeline 修复。
- 局限：领域集中在 VSR 推理管线，故障是人工冻结的确定性集合；PDF 前 8 页未覆盖完整消融和更多模型/仓库泛化。
- 阅读建议：优先精读。重点看 framework、runtime feedback、accept/rollback 和 fault set 设计。
- 证据来源：arXiv PDF 前 8 页，含摘要、引言、方法和实验设置。

## General Agent

### 2. MobileMem: Learning from a Year of Mobile Experiences

- 问题背景：个人助理型 agent 需要跨应用、跨时间、跨模态积累用户经验，但现有 memory benchmark 多停留在聊天记录或孤立事实，难以测试“记住过去、理解现在、适应未来”。
- 核心方法：MobileMem 构造一个面向 on-device memory layer 的 benchmark 和数据合成框架。它先用 prior knowledge/persona 建用户知识图谱，再用 KEME 在时间约束下合成长程用户-app session 轨迹，并生成需要多跳、时间推理、知识更新、隐式偏好推断和拒答能力的 QA。系统架构上，它把系统级 assistant memory 看成黑板，应用侧 memory 看成专门知识源，assistant 作为 controller 读取全局状态并协调检索。
- 创新点：最有价值的是“经验流”而非“事实库”的建模。它把 memory benchmark 从 retrieval accuracy 推向长期轨迹、一致性、更新和遗忘控制，也自然对应 agent 训练中的 episodic memory、context compression 和 cross-app tool-use。
- 实验与 benchmark：PDF 目录显示包含 MobileMem 文本场景和 MobileMem-Omni 多模态场景，评测覆盖多跳推理、时间推理、知识更新、隐式偏好和 abstention；答案通过 LLM-as-a-Judge 协议评估。前 8 页只覆盖任务定义、架构和合成流程，未完整读到主结果表。
- 可迁移价值：可以把“用户-app session”换成“开发者-仓库 session”或“researcher-browser session”，生成 Code/Search Agent 的长程记忆训练轨迹。
- 局限：大量依赖合成轨迹和 judge，真实隐私约束与长期在线更新成本仍需验证。
- 阅读建议：值得加入 related work，后续应补读第 4-6 节结果和应用。
- 证据来源：arXiv PDF 前 8 页，含摘要、引言、问题形式化和 benchmark scenario。

### 3. Emergent Models: Intelligence from Tiny Substrates

- 问题背景：论文反思主流深度网络的闭式输入输出映射，提出是否可以用更简单、开放的 dynamical substrate 通过迭代产生任务行为，并获得更好的外推归纳偏置。
- 核心方法：Emergent Models 把 cellular automata、neural cellular automata、ODE-like substrate 等看作 latent state 上的可迭代计算系统，通过 encoder/interface 接外部输入输出，用 evolutionary search 训练初始状态或软参数。理论上讨论 latent-universal：固定更新规则和接口，只改变初始 latent state，就可实现任意 partial computable function。
- 创新点：对 agent 研究的启发不是直接提升 LLM，而是提供“可搜索的 latent program / 可演化 runtime”的范式。它和 agent skill、tool policy、环境程序合成有交集：训练可以看成在状态空间里搜索可复用程序，而非只拟合 prompt 到 answer。
- 实验与 benchmark：前 8 页显示实验目的不是竞争 SOTA，而是验证非空性：20-300 参数量级的最小模型在简单算术函数上外推、展示控制行为和 online adaptation。作者也明确说明实验没有证明 tested substrate 的 latent universality。
- 可迁移价值：可作为 AutoForge/AgentSkiller 类工作中“技能 substrate”设计的理论参考，尤其是把 skill 表示成可演化初始状态而非自然语言片段。
- 局限：非常基础和概念性，训练效率、可扩展性、与 LLM agent 的接口都还不成熟。
- 阅读建议：作为思路储备阅读，不应当按实用 agent benchmark 论文看待。
- 证据来源：arXiv PDF 前 8 页，含摘要、引言、理论形式化和实验开头。

### 4. Omni-LiveAvatar: Minute-Level Real-Time Streaming Joint Audio-Video Avatar Generation

- 问题背景：这不是 Agent 论文，但它处理了长序列实时生成中的 bounded memory、rolling context 和 prompt planning，和长程 agent 运行时上下文管理有可迁移性。
- 核心方法：系统把大型双向 audio-video diffusion teacher 蒸馏成 few-step causal generator；推理时保留第一 macro-block 的 KV 状态作为 long-term memory，同时维护最近 L 个 macro-block 的 rolling KV cache 作为 short-term memory，并周期性 re-anchor long-term memory 减小 RoPE 位置差。层级 rolling prompt planning 把全局语义和局部 prompt 切开，减少长流式生成中的语义冲突。
- 创新点：它给出一个很工程化的长期/短期记忆组合：长期 anchor 负责身份、场景、音色等稳定约束，短期 cache 负责连续动作和语音同步。这对 browser/code agent 的长任务上下文也有启发：不是无限追加历史，而是维护稳定 anchor 加短窗上下文。
- 实验与 benchmark：基于 19B LTX-2，使用 8 张 H200 训练；和 LTX-2、Ovi、OmniForcing、Hallo-Live 比较。指标包括 VBench 视频质量、human fidelity、audio quality、Sync-C 和 H200 上 FPS。论文报告相对 teacher LTX-2 约 33x 速度提升；5 秒生成表中 Omni-LiveAvatar FPS 19.57，LTX-2 为 0.60。
- 可迁移价值：长短期 KV 预算、re-anchor、层级 prompt 规划可以借鉴到长程工具轨迹压缩。
- 局限：核心任务是生成式头像，不验证 agent planning 或 tool-use。
- 阅读建议：只读方法部分即可，作为 long-context runtime 设计参考。
- 证据来源：arXiv PDF 前 8 页，含摘要、方法和实验表。

### 5. Continual Evolution Strategies in Control Tasks

- 问题背景：非平稳环境中 agent 需要持续适应，但持续学习容易灾难性遗忘。论文关注 Evolution Strategies 在顺序控制任务中的表现，这对 agentic RL 的长期适应有间接启发。
- 核心方法：作者把 Hopper-v5、Walker2d-v5、Swimmer-v5 串成 task-agnostic continual control 流，策略不接收显式任务标签。普通 ES 每个任务顺序优化；replay 版本在当前任务训练时加入过往任务的额外 fitness evaluations，并把所有 fitness 共同 rank-normalize 参与更新，从而把搜索偏向能兼顾旧任务的参数区域。
- 创新点：它不是给神经网络加 replay buffer，而是把 replay 融入 black-box population search 的 fitness 估计。对 agent 训练的迁移点是：在环境/任务合成不断变化时，可用少量旧任务评测作为约束，防止后训练把原有工具能力冲掉。
- 实验与 benchmark：MuJoCo Hopper-v5、Walker2d-v5、Swimmer-v5；每 10 轮评估一次，每次 10 个 rollout；指标包括 normalized reward、backward transfer、forward transfer 和 acquisition interference。作者报告无 replay 时 Hopper/Swimmer 在后续任务后明显下降，replay 可显著降低任务切换后的崩塌，但过大 replay budget 会影响可塑性。
- 可迁移价值：适合设计 agent RL 的“旧能力回放评测集”和任务流顺序消融。
- 局限：控制任务规模小，和 LLM tool-use 之间还需要桥接。
- 阅读建议：读方法和指标定义即可。
- 证据来源：arXiv PDF 前 8 页，含摘要、方法和实验设置。

### 9. H2H Music Improv: A Communication Model and Audio-Visual Dataset for Music Improvisation

- 问题背景：实时 AI improvisation 系统通常把互动策略作为生成模型外层控制，而不是把沟通机制作为算法设计基础。虽然领域是音乐，但“互相发起、承认、进入稳定状态”的意图协议对 multi-agent coordination 有迁移价值。
- 核心方法：论文通过专家 improviser co-design 建立 machine-readable communication model，把二人即兴过程标注成时间线事件和状态：发起新想法、确认/响应、协商、稳定空间、转场等。数据集 H2H 包含双人音视频、每位演奏者的干净音轨，以及每人对自己意图和对方意图的独立标注。
- 创新点：最可迁移的是“双视角意图标注”：同一互动轨迹里同时记录 actor intended 和 partner perceived，这比单一动作标签更接近真实协作 agent 的误解、对齐和修正。
- 实验与 benchmark：数据集包含 37 段 duo free improvisation，总计 6 小时 8 分钟，来自 6 个 musician pairs、5 位专业/专家演奏者，涵盖 guitar、trombone、saxophone、trumpet。论文主要贡献是数据和标注协议，不是模型 leaderboard。
- 可迁移价值：可借鉴到 multi-agent tool-use 数据构造：为每一步保存“发起者意图”和“接收者理解”，训练 agent 判断何时澄清、跟随或切换策略。
- 局限：音乐场景强，离通用工具 agent 较远；缺少模型训练实验。
- 阅读建议：关注 annotation schema 和 dataset design。
- 证据来源：arXiv PDF 前 8 页，含摘要、通信模型和数据集统计。

## Search Agent / RAG / 证据工作流

### 6. Towards Scaling Qualitative Analysis of Video Data

- 问题背景：大规模视频质性分析需要维护视频、转写、编码、memo、证据链接和中间解释。传统多工具流程会打断证据链，AI 辅助也容易变成不透明解释权威。
- 核心方法：QualiVision 是一个 spreadsheet-backed workspace，把视频播放、transcript、coding streams、preliminary reports、visual summaries 和 AI prompts 同步到一个分析环境里。设计上强调 evidence preservation、cross-stream comparison、undo/redo、导出和同步桥，而 AI 只作为反思提示和 pattern surfacing，不替代人类解释。
- 创新点：对 Search Agent 很有启发：搜索/浏览 agent 的工作台不应只存最终答案，而应保存证据片段、编码标签、解释演化和可回溯 provenance。它把“引用可信度”落在 UI/data model 层。
- 实验与 benchmark：目前是 design probe / preliminary prototype。作者计划用 Comparative Structured Observation，让参与者在传统多工具 workflow 和 QualiVision 上做 open coding、发现模式、回溯证据，并收集 completion time、cognitive load、usability、think-aloud 和 post-study 数据。尚未报告正式结果。
- 可迁移价值：适合启发 deep research agent 的 evidence board：候选网页、PDF 段落、引用、笔记和报告段落双向绑定。
- 局限：原型阶段，缺少正式用户研究和 agent 自动化指标。
- 阅读建议：作为系统设计参考，重点看数据模型与 AI 介入边界。
- 证据来源：arXiv PDF 前 8 页，含摘要、引言、架构和拟议评测。

### 8. Adaptive Protection for Evolutionary Feature Construction in Symbolic Regression with Application to Credit Classification

- 问题背景：进化式 feature construction / symbolic regression 能自动搜索有用表达式，但 genetic operators 容易破坏已发现的重要 building blocks。
- 核心方法：作者在遗传操作前保存原始 constructed features，之后按 feature importance 计算保护分数，对重要特征进行更强恢复或保护；低重要度特征仍可被修改，以保留探索空间。importance 可来自 ridge 系数、SHAP、marginal contribution、random decision tree impurity 或 logistic regression 系数。
- 创新点：对 Search Agent / Code Agent 的迁移点是“保护高价值中间构件”的搜索控制。搜索型 agent 在演化 query plan、tool chain 或修复补丁时，也会破坏已有有效片段；可以用 evaluator attribution 或历史收益给组件分配保护强度。
- 实验与 benchmark：98 个 PMLB regression benchmark，并在 Australian Credit 和 German Credit 两个信用分类数据集上测试迁移；比较不同 protection coefficient、importance metric 和 base learner。前 8 页读到数据集与机制，未读到完整结果表。
- 可迁移价值：可用在自动 prompt/program/search-plan evolution：保留高贡献步骤，允许低贡献步骤变异。
- 局限：任务是表格 symbolic regression，和文本/工具 agent 仍需重新定义 feature importance。
- 阅读建议：读 Algorithm 1 和实验设置即可。
- 证据来源：arXiv PDF 前 8 页，含摘要、方法和数据集设置。

### 7. Measuring Fairness in Large Audio Language Models via Semantic-Aware Bias Estimation

- 问题背景：LALM 在 ASR 和 audio QA 中的 subgroup 差异可能来自真实偏差，也可能来自语义内容、说话人、口音等混杂因素。直接比较错误率容易误判。
- 核心方法：论文用 semantic-aware mixed-effects regression 控制混杂：把 reference text 的句向量作为语义协变量，把 speaker identity 建模为 random effect；更特别的是，语义向量由被评估的同一个 LALM 抽取，使控制变量贴近模型自身的语义感知。
- 创新点：对 agent eval 的启发是：做 subgroup / task-family 比较时，不应只比较整体成功率，而要控制任务语义复杂度、用户/环境随机效应和模型自己的表示空间。这个思路可以迁移到 search/code agent 的公平性、鲁棒性或任务难度校准。
- 实验与 benchmark：论文称在 synthetic data 和 real-world ASR/audio QA benchmarks 上验证，并报告控制语义和 speaker 后可减少 spurious fairness findings。前 8 页尚未读到具体 benchmark 名称和数值表。
- 可迁移价值：可作为 agent benchmark 分层分析方法：把 task embedding、repo identity、网站来源等作为协变量。
- 局限：与 tool-use agent 间接相关；完整实验结果需继续阅读后半部分。
- 阅读建议：方法值得借鉴，领域结果可略读。
- 证据来源：arXiv PDF 前 8 页，含摘要、引言、方法动机。

### 10. AlignFace: Human-Aligned Face Similarity Metric with Interpretable Concept Relations

- 问题背景：生成式人脸内容的评测若只用 SSIM、LPIPS 或黑盒感知指标，可能和真实人类感知不一致，并误导生成模型调试。
- 核心方法：AlignFace 用 FACETS 人类标注数据训练可解释相似度模型：VLM 编码人脸对和文本属性，gated cross-attention 抽取属性级差异，concept bottleneck 约束为可解释 face attributes，再用 neural GAM 建模属性对整体相似度的非线性影响，并考虑 own-group bias。
- 创新点：虽然不是 agent 论文，但“认知原则 + 概念瓶颈 + 非线性可解释评分”可迁移到 agent trajectory evaluator：不要只训练黑盒 reward model，而要把人类可理解维度作为中间概念，再学习其非线性权重。
- 实验与 benchmark：FACETS 包含 face triplets、整体和属性级相似度判断，覆盖 20 个认知基础的人脸属性；实验与 heuristic、learned perceptual、cross-modal baselines 比较整体、属性级和 subgroup human alignment。前 8 页读到总体结果描述，未读到完整数值。
- 可迁移价值：用于启发可解释 reward/rubric model，特别是把 agent 轨迹拆成 plan quality、evidence use、tool safety、verification 等概念。
- 局限：领域是视觉人脸相似度，迁移到 agent 需要重建概念集和标注协议。
- 阅读建议：只需读模型结构与 FACETS 标注设计。
- 证据来源：arXiv PDF 前 8 页，含摘要、引言、模型和数据集介绍。

## 今日重点趋势

1. 最强趋势是“闭环执行证据替代静态评测”：LoopVSR 通过真实推理、telemetry、CER 和回滚构造可验证修复循环。
2. 长程 memory 正在从“检索事实”转向“建模经验流”：MobileMem 的 cross-app trajectory 与知识更新比普通 RAG benchmark 更接近真实个人 agent。
3. 多篇弱相关论文都在处理“可保留的中间结构”：Omni-LiveAvatar 的 long/short memory、Adaptive Protection 的重要构件保护、QualiVision 的证据链保存，都是 agent runtime 可以借鉴的工程模式。

## 潜在研究 idea

1. 做一个 Code Agent Loop Engineering benchmark：每个任务包含受限 workspace、外部 evaluator、telemetry、hidden set 和 rollback policy，训练 agent 学会最小假设修复。
2. 将 MobileMem 的 KEME 改造成 ResearchMem：从浏览、PDF 阅读、笔记和引用生成长程 research trajectories，评测 search agent 的跨天记忆更新和证据复用。
3. 为 agent trajectory reward model 引入 concept bottleneck：先标注计划清晰度、证据可追溯性、工具选择、验证充分性、失败恢复，再学习最终偏好。
4. 在 agent RL 中加入 replay-based capability retention：每轮新环境训练都混入旧工具/旧 repo/旧网页任务的少量评测，监控 backward transfer。
