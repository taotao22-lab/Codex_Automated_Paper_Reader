## General Agent

### 1. SoundscapeAgent: Agentic Soundscape Construction for Controllable Synthesis and Scalable Audio-Language Supervision

- 方向：General Agent / agentic data construction
- 综合分：4.62
- 链接：https://arxiv.org/abs/2607.21857
- 证据来源：PDF 前 8 页；摘要中的 demo/code 信息未额外验证。

**问题背景**：单次 text-to-audio 生成通常把场景规划、素材选择、时间排布和渲染混在一个黑盒输出里，用户很难检查中间决策，也难以把生成过程复用成训练数据。对 Agent 训练来说，这个问题很熟悉：如果只保存最终答案，后续模型学不到任务拆解、工具选择、检索失败补救和可编辑计划。

**核心方法**：论文把声音场景生成拆成显式 agentic pipeline：LLM agent 先把用户意图转成可执行 scene plan，再为每个事件选择检索素材或按需生成素材，随后用确定性 timeline scheduler 渲染多事件混音，并导出对齐的场景元数据。PDF 中的系统图明确列出 intent parsing、planning、fuzzy/strict retrieval、audio QA、stems 和 listener/objective metrics。它不是让 LLM 直接吐波形，而是让 LLM 负责结构化计划，runtime 负责可验证执行。

**创新点**：新意不在音频模型本身，而在把“生成数据”改造成“可检查、可编辑、可复用的 agent 执行轨迹”。这对 General Agent 的迁移价值很直接：真实工具使用数据也应保存计划、工具选择、检索资产、执行结果和 QA 信号，而不是只保存 prompt/completion。

**实验与 benchmark**：Track A 评估可控生成质量，对比 AudioLDM 2 等 text-to-audio baseline，并用 5 分 listener study 与客观指标评估；Track B 用 50k/100k/200k agent-generated examples 做数据增强，在 MMAU test-mini 上验证音频理解/推理能力。PDF 显示 200k agentic augmentation 的整体 accuracy 到 56.50%，并在 Sound、Eco-Acoustic Knowledge 等子任务有明显增益。作者也指出 Speech 子任务较混合，说明 agentic 合成数据更偏向组合性场景理解。

**可迁移价值**：适合借鉴到 Agent post-training 数据构造：把“用户目标 -> 计划 -> 工具/素材获取 -> deterministic execution -> QA -> 元数据”的链条保存成训练样本。尤其适合生成浏览器、检索、代码执行和文件操作任务的可审计轨迹。

**局限**：音频领域强相关，资产库质量和 prompt 分布会限制泛化；PDF 前 8 页没有完整覆盖所有附录和 demo 实现细节。

### 2. Listen, Do Not Copy: Internalizing Audio-Grounded Scaffold Context for Robust Omni-Model Speech Understanding

- 方向：General Agent / post-training scaffold / GDPO
- 综合分：4.57
- 链接：https://arxiv.org/abs/2607.21943
- 证据来源：PDF 前 8 页。

**问题背景**：多模态模型在重叠说话和噪声环境中容易失败。直接给场景文字提示会让模型“复制上下文”而不是听音频，分数看似提升，实际能力没有内化。Agent 训练也有同样问题：如果 scaffold 泄露答案，模型只学会走捷径，不学会用工具验证。

**核心方法**：AGSC 提供“线索而非答案”：目标说话人活动、噪声水平、部分且打乱的词集合等有限 scaffold。论文加入 answer-overlap screen 和 silent-audio control，检查文本线索是否可直接替代音频。训练路径有两类：SFT 让模型在训练时使用 scaffold、测试时移除 scaffold，以 no-clue 改善衡量内化；GDPO 则把 streaming 控制拆成格式、gate 和 transcript rewards，训练模型何时使用线索以及如何输出说话人归属 transcript。

**创新点**：它把“防复制测试”变成训练协议的一部分，而不是事后诊断。对 Agent RL 很有价值：工具提示、检索摘要、单元测试日志都可能泄露答案，训练集应加入 silent/no-op/answer-overlap 类控制，验证模型是否真的依赖环境反馈。

**实验与 benchmark**：论文构造 CSB，覆盖 overlap、noise、meetings 和 streaming clue maturity；评估 Qwen3-Omni、MiniCPM-o、Ming-flash-omni。核心指标是 capped mean permutation WER、Mandarin CER 和 gating F1。PDF 显示 answer-bearing context 可把准确率从约 53% 拉到 94%，但 silent test 暴露复制；AGSC SFT 后 no-clue overlap+noise mpWER 从 25%-71% 降到 9%-15%。Gate-only GDPO 的 timeline F1 达 0.753-0.803，高于检测器触发的 0.53。

**可迁移价值**：可直接迁移到 Agent post-training：scaffold 只给不可复制的中间线索；训练后移除 scaffold 测 no-scaffold 能力；RL reward 分离 gate/format/content，避免一个容易 reward 掩盖真正任务 reward。

**局限**：任务是语音理解，不是工具 Agent；full-chain GDPO 仍有 gate collapse 风险，作者也报告重训练会伤害复杂段 recall。

### 3. Music-JEPA: Learning a World Model of Sound from Action

- 方向：General Agent / world model / planning
- 综合分：4.31
- 链接：https://arxiv.org/abs/2607.22000
- 证据来源：PDF 前 8 页。

**问题背景**：JEPA 常被用作被动表征学习，但真实 Agent 需要理解“行动会如何改变状态”。音乐虽然不是通用工具环境，却提供了干净的 action-state 结构：当前音频状态加上 pianoroll/pedal 动作，预测未来音频状态。

**核心方法**：Music-JEPA 把音频作为 state，把 pianoroll 和 pedal 作为 action，用 state encoder、action encoder 和 ViT predictor 在 latent space 预测下一状态。训练使用 EMA teacher，避免表征坍塌；同时训练 inverse/action predictor，使模型可通过规划搜索能解释目标声音的 action，从而做 piano transcription。

**创新点**：它把 world model 从“预测未来观测”推进到“动作条件下预测未来状态”，并把 latent planning 接到转录任务。对工具 Agent 的启发是：环境模型不应只总结上下文，还应学习 tool action 对 state 的影响，例如文件编辑、网页导航、检索查询会如何改变后续可见状态。

**实验与 benchmark**：训练数据为 MAESTRO v3.0.0，约 200 小时钢琴音频/MIDI。评估包括状态-动作扰动敏感性、ASAP beat tracking、MAESTRO composer identification、pseudo key recognition，以及 planning-based piano transcription。PDF 表格显示 Music-JEPA 在多个 MIR 下游任务上优于 audio-only JEPA，并在动作扰动中表现出对 state-action-target mismatch 的高敏感性。

**可迁移价值**：适合借鉴到 tool-use world model：把工具调用作为 action token，预测环境 latent state，再通过 inverse planning 或 policy search 找到达成目标的动作序列。

**局限**：动作空间是钢琴 MIDI，远比网页/代码环境规整；作者也指出 dense latent action 的稳定规划仍困难。

### 4. Evolving Self-Organising Agents Without Fitness: Three Falsifiable Experiments from Constraint-Driven Selection to Developmental Encoding

- 方向：General Agent / environment and curriculum design
- 综合分：3.99
- 链接：https://arxiv.org/abs/2607.21630
- 证据来源：PDF 前 8 页。

**问题背景**：很多 Agent/RL 流程依赖单一标量 reward，但开放式能力增长可能需要更接近环境约束、生态压力和多样性保护的机制。Genesis 研究的是没有 designer-specified fitness 时，agent 是否还能形成演化动力学。

**核心方法**：Genesis 让 512 个 agent 在 Gray-Scott reaction-diffusion substrate 上行动，动作包括 Move、Secrete、Idle。它用 metabolic cost、Physics Gatekeeper、adaptive constraint regulation 和 relational dominance 替代标量 fitness。论文连续测试三个假设：完全移除 fitness 后是否仍有活动；agent-mediated niche construction 是否能突破复杂度平台；CPPN indirect encoding 加 NEAT-style speciation 是否能保护结构复杂化。

**创新点**：可贵之处是把失败也设计成可证伪实验：V3 用 sham-control 扣除分泌成本但抑制环境写入，隔离 niche construction 的因果贡献。对 Agent 评测来说，这是一种很好的 benchmark 设计方式：把“环境改变本身”“行动成本”“策略复杂度保护”分开做控制实验。

**实验与 benchmark**：V2 做 12 个独立 10,000 generation run；V3 做 20 runs × 50,000 generations，共 1,000,000 agent-generations；V4/V5 用 CPPN/NEAT-style speciation 检查结构复杂化。PDF 中报告 V3 real/sham 的 EPC growth 都为 0、LZ76 action-trace complexity 都为 0.068，说明被动 niche construction 不足以突破平台。

**可迁移价值**：适合用于设计 General Agent sandbox：少依赖单一 reward，多记录生存约束、行动成本、行为多样性、sham-control 和复杂度诊断。

**局限**：不是 LLM Agent；open-ended evolution 与工具使用训练之间仍需工程桥接。

### 5. Closed-Loop Generative Selection: Convergence, Memory, and Noisy Oracles

- 方向：General Agent / closed-loop data-selection theory
- 综合分：3.95
- 链接：https://arxiv.org/abs/2607.22211
- 证据来源：PDF 前 8 页；领域是 drug discovery，迁移解释为本文推断。

**问题背景**：闭环生成选择的基本形态是：生成模型提出候选，oracle 评分，保留 elite set，再用 elite set 训练下一轮模型。Agent 训练中的自举任务生成、测试器评分、失败样本再训练也很像这个循环，但通常缺少收敛、记忆深度和 noisy oracle 分析。

**核心方法**：论文把 retrained generator 纳入扩展状态空间，恢复 Markov 结构；在 elitism 下证明吸收结构、almost-sure convergence 和 layered hitting-time bound。随后分析 full memory、finite m-step memory、non-monotone learning 下的 optimal memory depth，并扩展到 multi-objective 与 noisy oracle，包括 sub-Gaussian 和 heavy-tailed noise 下重复评估/robust mean 的成本。

**创新点**：它明确指出“记忆越深不总是越好”：当学习随数据单调改善时深记忆不坏；非单调时过多历史会拖慢逃离低 fitness level。对 Agent 数据飞轮来说，这能解释为什么老失败轨迹、过时网页状态、旧测试器信号可能污染训练。

**实验与 benchmark**：PDF 前 8 页主要是理论框架和 binary-string oracle 示例，后续实验用于确认三类理论预测：almost-sure convergence、exploration 保持、memory 的条件性收益。没有看到 LLM Agent benchmark。

**可迁移价值**：可作为自举式 Agent 训练循环的理论参考：记录 oracle 噪声、限制记忆窗口、对高价值样本做重复验证，并把评估预算当作瓶颈。

**局限**：原应用是分子/材料闭环搜索，非 Agent；数学假设与真实 LLM 训练循环差距较大。

## Search Agent

### 6. Unsupervised Multimodal Intent Discovery via MLLM-Guided Concept Generation and Semantic Propagation

- 方向：Search Agent / semantic clustering and propagation
- 综合分：3.55
- 链接：https://arxiv.org/abs/2607.21908
- 证据来源：PDF 前 8 页。

**问题背景**：无监督意图发现常依赖 embedding 几何相似度，容易产生不可解释或边界不稳的 cluster。Search Agent 面对网页、证据、query intent 时也有类似问题：只靠向量近邻不一定知道每个簇的语义角色。

**核心方法**：MCSP 先做 multimodal contrastive pretraining，再从每个 cluster 选高置信代表样本，让 MLLM 对目标簇和邻近簇做 contrastive reasoning，生成显式 semantic concepts。之后构建 concept-aware neighborhood graph，用 random-walk semantic propagation 把概念证据扩散到局部结构，并用 concept-supervised contrastive objective 反过来重塑 embedding manifold。

**创新点**：把 LLM/MLLM 当作“概念锚点生成器”，再用图传播把稀疏高质量语义扩展到全集。对 Search Agent 可迁移到 query/session clustering、网页证据分组、任务意图归纳和检索轨迹压缩。

**实验与 benchmark**：论文在三个 multimodal intent discovery benchmark 上评估，指标包括 ACC、ARI、NMI、FMI；MCSPQwen 和 MCSPGemini 均超过 UMC。PDF 中 ablation 显示去掉 graph propagation 时三个数据集分数分别大幅下降，说明概念传播不是装饰模块。

**局限**：原任务是 multimodal dialogue intent discovery，不是开放网页搜索；概念质量受代表样本、class imbalance 和 MLLM 偏差影响。

### 7. Reflector: Arrangement-Aware Harmonic Retrieval for Sample-Based Composition

- 方向：Search Agent / dynamic retrieval system
- 综合分：3.37
- 链接：https://arxiv.org/abs/2607.22413
- 证据来源：PDF 前 8 页。

**问题背景**：固定 query 的检索在交互式创作中会失效，因为用户不断加入新素材，真正的检索意图随上下文改变。Search Agent 的多轮检索也一样：后续 query 应该根据已采纳证据和任务状态动态更新。

**核心方法**：Reflector 用手工 interval-class oracle 给 pitch-class compatibility 打分，再用纯 synthetic audio 训练 128-D encoder 近似 oracle。系统在多轨 timeline 上用 sweep-line 找 co-sounding regions，计算 oracle-weighted centroids，并用当前 session 的 composite harmonic identity 检索新样本。检索分两阶段：先 embedding dot-product 排序，再做 transposition re-ranking。

**创新点**：它把“检索 query”从单个参考样本改成随 session 演化的 centroid，并保留 dispersion 等诊断量。对 Search Agent 的迁移是：把已读证据、当前假设、未解决子问题聚合成可更新 query state，而不是每轮从用户原始问题重搜。

**实验与 benchmark**：PDF 前 8 页是系统论文，使用 631 个样本的 working library 做 intrinsic characterization；报告 68% 的 top-10 query pairs 在非零 transposition 下兼容性更高。没有通用 IR benchmark。

**局限**：强音乐领域，oracle 是人工规则；迁移到文本/网页检索需要替换 compatibility oracle。

### 8. CODA: Cascaded Online Discontinuity-Aware Alignment for Real-Time Image-Based Score Following

- 方向：Search Agent / online alignment and recovery
- 综合分：3.28
- 链接：https://arxiv.org/abs/2607.21899
- 证据来源：PDF 前 8 页。

**问题背景**：实时 score following 要在流式音频中定位乐谱位置，重复、跳转和 coda 会破坏线性对齐。Search/Browse Agent 的长任务也有类似“轨迹断裂”：页面跳转、检索分支或上下文重排后，系统要恢复正确位置。

**核心方法**：CODA 把定位分解为级联选择：先选 system，再在 system 内选 bar，最后定位 note。这样把全局搜索空间逐级缩小，并保证几何一致性。模型用 causal Mamba audio encoder、共享 CNN visual backbone、beam search 和 learned temporal priors；遇到 silence-driven break mode 时放宽 temporal constraints 以恢复任意跳转。

**创新点**：它不是让模型直接回归最终位置，而是利用文档结构做 cascaded decoding。对 Search Agent 可借鉴为“网页/文档结构级联定位”：先定位站点/页面块，再定位段落/证据句，遇到跳转时用 break mode 重新拓宽 beam。

**实验与 benchmark**：基于 MSMD piano benchmarks。PDF 显示 CODA 2.0M trainable parameters，12.8 ms/frame，78.1 fps，满足 20 fps 实时预算；Setting I bar/system accuracy 达 .975/.991。repeat-aware jump test 中 full CODA 在 repeat 子集 1s recovery .78、2s recovery .91，平均 latency 0.72s。

**局限**：只在 solo piano/MSMD 上训练评估；不是文本检索任务。

## Code Agent

### 9. On the Runtime Analysis of Reinforcement Learning Hyper-Heuristics

- 方向：Code Agent / RL operator selection theory
- 综合分：3.56
- 链接：https://arxiv.org/abs/2607.22036
- 证据来源：PDF 前 8 页。

**问题背景**：Code Agent 在修复代码时会在多种低层操作间切换：改测试、改实现、缩小 repro、调整搜索策略。Hyper-heuristic 研究的问题类似：根据当前优化阶段自动选择 low-level heuristic。

**核心方法**：论文分析 RLHH，即给每个 heuristic 维护权重，成功时乘 reward term，失败时乘 penalty term，再按权重概率选择算子。它关注 LeadingOnes benchmark 和两个算子 RLS1/RLS2：前半阶段 RLS2 更有效，过半后 RLS1 更有效。作者证明合适参数下 RLHH 能学习这一阶段切换，达到两算子可实现的最优期望运行时间。

**创新点**：对 Agent 策略选择的启发是“阶段相关的最佳工具/动作”可以被理论化，而不是固定 policy。Code Agent 的修复循环也可能存在阶段切换：早期探索用宽搜索，后期收敛用局部补丁和测试。

**实验与 benchmark**：主要 benchmark 是 pseudo-Boolean LeadingOnes。PDF 给出理论目标：使用 RLS1/RLS2 的最优 expected runtime 约为 0.42329 n^2，并说明实验显示 RLHH 比已证明最优到低阶项的 Generalised Random Gradient HH 更快。

**局限**：理论任务很简化，距离真实代码仓库修复、SWE-bench 或工具调用轨迹很远。

### 10. Genesis: An Empirical Platform for Studying Open-Ended Evolution Without Fitness Functions

- 方向：General Agent / companion paper
- 综合分：3.17
- 链接：https://arxiv.org/abs/2607.21631
- 证据来源：PDF 前 8 页；与 2607.21630 高度重叠。

**问题背景与方法**：这篇是 Genesis 平台的更短系统概述，强调 constraint-driven selection、relational dominance、adaptive regulation、PNCT metrics 和 meta-evolution of physics。它报告 7/12 runs 在完全移除 fitness 后仍维持 evolutionary activity，并说明 V3 做了 20 runs、共 1 million generations 的 sham-control。

**创新点**：相对 2607.21630，它更像平台摘要，清楚列出 Genesis 架构组件和 future direction：让 governing physics 自身可演化。对 Agent 环境生成来说，这提示我们可以让任务环境规则、约束强度或干扰分布成为训练对象，而不只是固定 benchmark。

**实验与 benchmark**：PDF 前 8 页包含 12 个 10,000-generation runs、V3 1 million generation sham-control、早期 V4/V5 validation 信息；没有 LLM Agent benchmark。

**局限**：与第 4 篇重复，建议只把它作为 related work 补充，不必深读两遍。

## 今日重点趋势

1. **Scaffold 必须防复制**：AGSC 的 silent-audio control 很适合迁移到工具 Agent，检查模型是否真的使用环境反馈，而不是复制提示里的答案。
2. **数据构造正在 agentic 化**：SoundscapeAgent 显示可执行计划、素材获取、确定性渲染和 QA 元数据可以成为训练数据资产。
3. **世界模型应 action-conditioned**：Music-JEPA 提醒我们，Agent 环境表征要学习 action 对 state 的影响，而不仅是压缩上下文。
4. **闭环训练要管理记忆和 oracle 噪声**：Closed-loop generative selection 的理论对自举式 Agent 数据飞轮有直接警示。
5. **动态检索比静态 query 更重要**：Reflector 和 CODA 虽是音乐系统，但都强调随上下文更新检索/定位状态。

## 潜在研究 idea

- 为 Code/Search Agent 构造 **no-answer scaffold**：给日志、检索摘要、测试结果的结构化线索，但用 overlap/silent/no-op 检查防止答案泄露。
- 把浏览器或代码仓库状态编码成 latent state，训练 **tool-action-conditioned world model**，预测点击、查询、编辑、测试后的状态变化。
- 在 Agent 数据飞轮中显式控制 memory window：比较只用最近失败轨迹、全历史轨迹和去噪 elite 轨迹对 RL/SFT 的影响。
- 用 sham-control 评估环境合成：保留行动成本但抑制环境写入，确认 agent 性能提升是否真的来自交互反馈。
- 把 Search Agent 的 query state 做成 session centroid：已采纳证据和未解决 claim 动态改变后续检索方向。
